## Brand & Style
The design narrative centers on focused delight, cognitive clarity, and calm playfulness. Built for students taking analytical breaks and puzzle enthusiasts seeking mindful engagement, the aesthetic removes all noisy distractions while preserving tactile satisfaction.

The visual style is **Soft Modern Tactility**: a hybrid of Swiss geometric precision and subtle, organic softness. It couples crisp light slate backdrops with pristine white surfaces, rhythmic micro-elevations, and cheerful, soft pastel color accents. Physical interaction cues (subtle inset presses, smooth slide springs, and spatial micro-transitions) evoke the tactile pleasure of moving real, polished wooden or matte acrylic puzzle blocks across a smooth lacquer tray.

## Colors
The palette balances an ultra-clean, low-contrast neutral framework with high-chroma, low-saturation pastel tints that lend character to each puzzle segment.

### Background & Canvas
- **App Canvas**: `#F8FAFC` (Slate 50) — Crisp, glare-free, airy.
- **Surface Elevation 0 (Board Well)**: `#F1F5F9` (Slate 100) — Inset tone defining the puzzle tray boundaries.
- **Surface Elevation 1 (Card / Modal Background)**: `#FFFFFF` (Pure White).

### Neutral Spectrum
- **Text Primary**: `#0F172A` (Slate 900) — High-contrast, sharp legibility for headings and tile indices.
- **Text Secondary / Guidance**: `#475569` (Slate 600) — Calm, functional hints and secondary scores.
- **Muted / Inactive**: `#94A3B8` (Slate 400) — Keyboard key cap borders and empty slots.
- **Borders & Dividers**: `#E2E8F0` (Slate 200) — Crisp architectural outlines.

### Vibrant Pastel Tile System
Every tile category or numeric block leverages a tinted pastel background paired with its corresponding deep-tone ink for accessibility (contrast > 4.5:1):
- **Mint Sage**: Fill `#DCFCE7`, Border `#86EFAC`, Text `#14532D`
- **Sky Blue**: Fill `#E0F2FE`, Border `#7DD3FC`, Text `#0369A1`
- **Soft Indigo**: Fill `#E0E7FF`, Border `#A5B4FC`, Text `#3730A3`
- **Lavender Violet**: Fill `#F3E8FF`, Border `#D8B4FE`, Text `#581C87`
- **Blush Rose**: Fill `#FFE4E6`, Border `#FDA4AF`, Text `#881337`
- **Warm Coral**: Fill `#FFEDD5`, Border `#FDBA74`, Text `#7C2D12`
- **Golden Amber**: Fill `#FEF3C7`, Border `#FCD34D`, Text `#78350F`

### Interactive Accents
- **Primary Action (New Game / Play)**: Deep Indigo (`#4F46E5`), Hover (`#4338CA`), Active (`#3730A3`).
- **Success / Victory Accent**: Emerald Green (`#059669`).

## Typography
The system uses **Outfit** for structural clarity and expressive numerical display, paired with **Plus Jakarta Sans** for crisp labels, status indicators, and guidance text.

- **Numerals & Metrics**: Handled by Outfit. Numbers are rendered with tabular figures (`font-variant-numeric: tabular-nums`) so timer increments and move counters do not induce horizontal layout jitter.
- **Hierarchy Rules**: Display headings use a tightened letter-spacing (-0.02em) to anchor the card without consuming unnecessary vertical real estate. Subtitles and keyboard helper annotations feature uppercase tracking (+0.04em) to maintain instant legibility at tiny scales.

## Layout & Spacing
The layout follows a centered, distraction-free **Fixed Grid System** constrained to a max-width of 540px on desktop and a fluid single-column layout on mobile devices.

### Board Geometry
- The 4x4 puzzle board is strictly square (`aspect-ratio: 1 / 1`), adapting smoothly between 300px (mobile) and 440px (desktop/tablet).
- **Tile Gaps**: 8px (`0.5rem`) on mobile screens, scaling up to 12px (`0.75rem`) on desktop.
- **Board Inset**: 12px padding framing the tiles inside the recessed well.

### Breakpoints & Flow
- **Mobile (<640px)**: Tight vertical stack. The header, stat badges (horizontal 2-column strip), puzzle board, and quick-action bar stack with 16px (`space-md`) vertical separation.
- **Desktop (≥640px)**: Centered card container with 32px padding, flanked by unobtrusive sidebar shortcuts or anchored floating bottom helpers for keyboard navigation.

## Elevation & Depth
Depth conveys physical tactile feedback, differentiating fixed frames, recessed slots, and actionable floating tiles.

- **Recessed Well (Board Base)**:
  `box-shadow: inset 0 2px 4px 0 rgba(15, 23, 42, 0.06), 0 1px 2px 0 rgba(15, 23, 42, 0.03);`
  Creates a shallow physical tray where puzzle tiles sit.

- **Puzzle Tile (Rest)**:
  `box-shadow: 0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05), inset 0 1px 0 rgba(255, 255, 255, 0.8);`
  A light top highlight combined with ambient bottom fall-off gives tiles an inviting, extruded chip feel.

- **Puzzle Tile (Hover & Slide Animation)**:
  `box-shadow: 0 8px 12px -2px rgba(15, 23, 42, 0.10), 0 4px 6px -2px rgba(15, 23, 42, 0.05);`
  Slightly rises along the Z-axis, with a snappy spring timing function (`cubic-bezier(0.34, 1.56, 0.64, 1)`).

- **Main Dashboard Card**:
  `box-shadow: 0 10px 25px -5px rgba(15, 23, 42, 0.04), 0 8px 10px -6px rgba(15, 23, 42, 0.02);`
  Extremely soft, atmospheric shadow on pure white cards over the `#F8FAFC` background.

- **Victory Modal Overlay**:
  `box-shadow: 0 25px 50px -12px rgba(15, 23, 42, 0.2);`
  Anchors focus while dimming background clutter via `backdrop-filter: blur(8px)`.

## Shapes
The shape language uses high-consistency rounded geometries (`roundedness: 2`, base radius 8px / `0.5rem`). 

- **Puzzle Board Tray**: 24px (`rounded-xl`) outer contour to provide an organic, friendly frame.
- **Puzzle Tiles**: 12px (`rounded-lg`) corner radii, retaining soft corners that prevent visual harshness when tiles align tightly in clusters.
- **Stats Badges & Keycap Indicators**: 10px corner radius with an intentional balance between mechanical keyboard keycaps and clean UI badges.
- **Buttons & Action Controls**: Fully rounded pills (9999px) for primary calls-to-action and 12px rounded-lg for functional toggle tools.

## Components

### 1. Puzzle Tiles
- **Structure**: Aspect ratio 1:1, full-height and full-width centered content. Built with high-contrast numerical label in `Outfit SemiBold/Bold`.
- **States**: 
  - *Default*: Soft pastel surface, subtle matching 1px border (`border-opacity: 0.6`), elevated tactile shadow.
  - *Movable Target*: Gentle cursor pointer; subtle 1.02 scale transform on hover.
  - *Inactive/Immovable*: Standard cursor, flat elevation without hover scale.
  - *Solved Position State*: Micro gold shimmer dot or subtle saturation boost indicating correct placement.

### 2. Gaming Stats Badges (Timer & Moves)
- **Structure**: Two or three inline cards displaying `Icon`, `Label` (Uppercase, slate-500), and `Value` (tabular Outfit bold, slate-900).
- **Style**: Pure white fill with `#E2E8F0` hairline border, padded at 12px 16px, incorporating a faint pastel-tinted dot (e.g., amber for moves, sky-blue for timer).

### 3. Keyboard Guidance Indicators
- **Keycaps**: Visual `<kbd>` elements mimicking physical scissor-switch keys. Rendered with `#F8FAFC` fill, `#CBD5E1` thick bottom border (giving 2px 3D depth), and slate-700 bold arrow glyphs (`↑`, `←`, `↓`, `→` or `W`, `A`, `S`, `D`).
- **Hint Text**: Accompanied by low-prominence label: "Use arrow keys or click adjacent tiles".

### 4. Action Buttons
- **Primary (Shuffle / Restart)**: Vibrant Indigo `#4F46E5` fill, white bold text, pill-shaped (`rounded-full`), padded 14px 28px. On press: `translate-y-0.5` with depressed shadow.
- **Secondary (Pause / Sound / Mode)**: `#F1F5F9` background, `#475569` icon/text, no border. On hover: `#E2E8F0`.

### 5. Celebratory Victory Modal
- **Backdrop**: Translucent slate `#0F172A40` with 8px Gaussian blur.
- **Card**: Pure white, 28px padding, 20px roundedness, centered confetti or milestone illustration at the crown.
- **Score Breakdown**: Grid summarizing completion time, total moves, and personal best with soft pastel badge highlights.
- **Button Group**: Dual-button layout offering "Play Again" (Primary) and "Share Score" (Secondary outline).
